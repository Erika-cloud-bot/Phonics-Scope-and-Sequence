Sync test

Checks whether this Chromebook can still reach your Sheet after you change the deployment's access setting. Delete this page once you're done with it.

1. The address

Paste your Apps Script web app address.

2. Can this device read the Sheet?

Exactly the request the progress page makes. This one gives a real answer — the browser can see whether Google replied.

3. Can this device write to the Sheet?

Exactly the request the practice app makes when a round finishes. The browser cannot see the reply to this one — that's how the real app works too — so the only honest check is whether the row appears in your Sheet.

Reading the result

  • Read passed and the test row appeared — domain restriction works from this device. That closes the door, and none of the workarounds are needed.
  • Read failed — Google isn't accepting this device as signed in. The write almost certainly failed too, silently. Put the deployment back to Anyone before students next use the app, or their rounds will queue up and never arrive.
  • Read passed but no row appeared — reads are authenticating and writes aren't. Tell me and I'll look at it; don't leave it in this state.
